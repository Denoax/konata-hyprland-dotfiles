# Notification center artwork

These are deterministic extractions from the approved Kona Notification Center
1:1 pack. Hero images are downscaled once to a 2x render asset. Icons, speech
bubbles, footer characters, and footer text are cropped or composed from the
supplied Light/Dark sheets with Lanczos filtering; no replacement art is generated. The current link is
selected from the authoritative Kona appearance mode by the existing
kona-dashboard one-shot entrypoint.
