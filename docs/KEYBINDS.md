# Keybinds

The authoritative definitions are in `.config/hypr/hyprland.lua`. This is the human map for the current checkpoint.

## Shell and menus

| Shortcut | Action |
| --- | --- |
| Tap `Super` | Pin/unpin the sidebar |
| Hover left edge | Temporary sidebar reveal |
| `Super + Space` | Application launcher |
| `Super + Shift + Return` | Notification/control center |
| `Super + Ctrl + Space` | Notification/control center |
| `Super + C` | Quick settings |
| `Super + Ctrl + I` | Kona Studio |
| `Super + F1` | Shortcut reference |
| `Super + Ctrl + M` | Kona Mosaic |
| `Super + X` | Desktop menu |
| `Ctrl + right-click` on desktop | Desktop menu |
| `Super + V` | Clipboard history |
| `Super + Shift + A` | Audio device menu |
| `Super + Ctrl + A` | Per-app audio mixer |
| `Super + Ctrl + P` | Profile picker |
| `Super + Shift + W` | Wallpaper picker |
| `Super + W` | Workspace overview |
| `Ctrl + Alt + Delete` or `Super + Escape` | Power/session menu |

## Applications and windows

| Shortcut | Action |
| --- | --- |
| `Super + Return` | Kitty |
| `Super + E` | Default file manager |
| `Super + B` | Browser |
| `Super + R` | Command launcher |
| `Alt + Tab` / `Alt + Shift + Tab` | Window switcher |
| `Alt + F4` or `Super + Q` | Close window |
| `Super + F` | Fullscreen |
| `Super + Shift + Space` | Toggle floating |
| `Super + H` or `Ctrl + H` | Minimize active window |
| `Super + Shift + H` | Restore most recent minimized window |
| `Super + D` or `Super + M` | Show desktop |
| `Super + arrow` | Focus window |
| `Super + Shift + arrow` | Move window |
| `Alt + left drag` | Move window |
| `Alt + right drag` | Resize window |

## Workspaces and system

| Shortcut | Action |
| --- | --- |
| `Super + 1…0` | Focus workspace 1…10 |
| `Super + Shift + 1…0` | Move active window to workspace |
| `Super + Ctrl + Left/Right` | Previous/next workspace |
| `Super + G` | Gaming mode |
| `Super + U` | Updates/recovery interface |
| `Super + Shift + N` | Night light |
| `Super + L` or `Super + Ctrl + L` | Lock with Hyprlock |
| `Super + Ctrl + S` | Save session |
| `Super + Ctrl + Shift + S` | Restore session |
| `Print` | Full screenshot |
| `Super + Shift + S` | Region screenshot and annotation |
| `Super + Shift + R` | Region recording |
| `Super + Ctrl + Shift + R` | Active-output recording |
| `Ctrl + Shift + Escape` | Task manager |

Media, volume, microphone, brightness, Caps Lock and Num Lock keys route through the existing Kona/SwayOSD owner.
